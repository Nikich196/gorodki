**12:49 — вход на сервере (этап 1, автономная часть).** [Как устроен вход](architecture/auth.md).

  отзывает весь вход. Окно не работает, если вход уже отозван, — иначе отзыв можно было бы обойти (нашёл при написании тестов).

- Всё закрыто по умолчанию; в базе хранится только SHA-256 refresh-токенов. Секреты (`Auth__SigningKey`) — только на Render.
- Вход через Google заработает, когда будет OAuth client ID (нужен аккаунт Google Cloud — issue #4); до этого `/auth/google` отвечает 503.
