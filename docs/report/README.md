# Пояснительная записка — каркас

Черновик записки к семестровому проекту (PLAN.md, §1: «подробная записка, скорее всего ГОСТ»). Главы пишутся здесь,
в Markdown, по ходу работы — рядом с кодом, чтобы текст не расходился с тем, что сделано. Оформление (ГОСТ, объём,
одна записка на команду или своя у каждого, Overleaf) — после ответов преподавателя (issue #3); тогда текст переносится
в шаблон как есть.

## Правила текста

- Писать о том, что сделано и проверено; планы — отдельно и с пометкой. Числа — из кода, тестов и замеров, не «на глаз».
- Аналоги называть честно (PLAN.md D13): чем похожи и чем отличаемся — с источниками.
- Каждый источник — в список источников с датой обращения.
- Роль ИИ-ассистента описать открыто (как — решает Никита).
