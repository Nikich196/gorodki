# 2. Требования к системе

Требования выведены из плана проекта (`docs/PLAN.md`) и сгруппированы по назначению. У каждого — номер, источник в плане
и состояние на дату записи. Состояния:

- **сделано** — реализовано, покрыто тестами и слито в основную ветку; в скобках — где (сервер, ядро игры на телефоне,
  пакет синхронизации);
- **в работе** — частично;
- **план** — запланировано, с этапом;
- **решение** — ждёт решения по правилам (номер задачи на GitHub).

Все числа правил хранятся в версионированном игровом конфиге (`contracts/game-config.v1.json`): телефон и сервер
проверяют забег одними и теми же числами, а изменение чисел не требует выпуска приложения.

## 2.1. Назначение

Мобильная игра для iPhone о захвате территории города Бреста бегом и на велосипеде: игрок обегает участок, и его
территорией становится многоугольник, точно повторяющий GPS-след. Второй режим — «Исследование»: город под туманом,
который открывается вокруг пройденного пути. Игра рассчитана на 200+ игроков (студентов БрГТУ и жителей города),
показ — на живом телефоне в конце декабря 2026 года (PLAN.md, §1).

## 2.4. Ограничения

- Команда — два человека по ~5 ч в неделю на двоих; основной код пишет ИИ-ассистент, команда должна понимать и
  защищать его (§1).
- До появления Mac приложение собирается только в CI; установка на телефон — без платного аккаунта, через Sideloadly
  с переподписью раз в 7 дней (D9). Поэтому «200+ игроков» реально только через TestFlight с платным аккаунтом; без него
  на телефонах играют 5–15 человек, остальным — веб-компаньон (D9; решение о платном аккаунте — к 20.10, issue #6).
- Бесплатные тарифы: сервер засыпает без запросов (пингер), база ограничена 500 МБ.
- Не делаются: Android, Apple Watch, чат, платежи, живые позиции друзей (§3.19, Won't).
