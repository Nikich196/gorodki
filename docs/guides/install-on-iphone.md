# Установка «Городков» на iPhone без Mac (Sideloadly)

Пока нет Mac и платного аккаунта разработчика, приложение собирает GitHub Actions,
а на iPhone его ставит программа **Sideloadly** на Windows. Подпись бесплатного Apple ID действует **7 дней**,
потом приложение нужно переустановить (или включить автообновление в Sideloadly).

Это же — **спайк S2** из плана: проверяем, что вся цепочка работает на iOS 27, включая расширение
(Live Activity и виджет) и App Group.

## Что понадобится

- Компьютер с Windows и кабель для iPhone.
- **Отдельный бесплатный Apple ID** только для подписи. Не основной и не платный аккаунт:
  программы подписи иногда отзывают сертификаты, и страдать должен «расходный» аккаунт.
  Проще всего создать его на https://account.apple.com («Создать Apple Account») и включить двухфакторную проверку.
  Если регистрация не проходит, попробуй без VPN: Apple иногда отказывает в регистрации через VPN.
- **iTunes и iCloud для Windows — версии с сайта Apple, не из Microsoft Store.** Sideloadly с версиями из Store не работает.
- **Sideloadly** — https://sideloadly.io (официальный сайт; больше ниоткуда не качать).

## Шаг 1. Скачать IPA

1. Открой https://github.com/Nikich196/gorodki/actions/workflows/ipa.yml (нужно войти в GitHub).
2. Нажми **Run workflow**, поставь галочку **probe** («Пробная сборка команды») и запусти. Подожди ~10 минут.
   Без галочки получится сборка для игроков: в ней нет «Проверки установки» и «Лаборатории».
3. Открой этот запуск. Внизу, в разделе **Artifacts**, скачай `gorodki-free-ipa-probe-…` — это zip с двумя файлами:
   - `gorodki-free-adhoc.ipa` — пробуем **первым**;
   - `gorodki-free-unsigned.ipa` — запасной, если с первым Sideloadly выдаст ошибку.
4. Распакуй zip.

Пробную сборку (`-probe`) ставь только на телефоны команды. Игрокам — артефакт без `-probe` в имени.

## Шаг 2. Установить

1. Подключи iPhone кабелем, на телефоне нажми «Доверять этому компьютеру».
2. Запусти Sideloadly. Вверху должен появиться твой iPhone.
3. В поле **Apple ID** — отдельный Apple ID из подготовки.
4. Перетащи `gorodki-free-adhoc.ipa` в окно Sideloadly.
5. В **Advanced options** ничего не меняй. Особенно **не ставь** галочку «Remove Extensions»: расширение мы и проверяем.
6. Нажми **Start**, введи пароль и код двухфакторной проверки. Дождись «Done».

Если вход Apple ID не проходит — напиши в чат текст ошибки. Одна из возможных причин — VPN.

## Шаг 3. Разрешить запуск на телефоне (один раз)

1. **Настройки → Основные → VPN и управление устройством** → твой Apple ID → **Доверять**.
2. **Настройки → Конфиденциальность и безопасность → Режим разработчика** → включить → перезагрузка → подтвердить.
   Переключатель появляется только после первой установки.

## Шаг 4. Проверка (это и есть спайк S2)

1. Открой «Городки». Вверху справа нажми **«Отладка»** (жучок) — там блок **«Проверка установки»**.
2. **Сделай снимок экрана** и пришли в чат. Там видно: версию iOS, bundle ID (не поменял ли его Sideloadly),
   до какого числа действует подпись, работает ли App Group.
3. Нажми **«Запустить Live Activity»** и заблокируй телефон. На экране блокировки должна появиться плашка
   «Городки · проверка» с таймером. Сделай снимок.
4. На экране «Домой» добавь виджет **«Городки»** (долгое нажатие → «+» → Городки). Виджет должен показать
   время последнего запуска приложения и «App Group работает». Сделай снимок.

| Что проверяем | Работает? |
|---|---|
| Приложение установилось и открылось | |
| Bundle ID не изменился | |
| Подпись действует 7 дней | |
| App Group работает | |
| Live Activity на экране блокировки | |
| Виджет показывает время запуска | |

## Если что-то не работает

- **Расширение не запускается** (нет плашки или виджета), а остальное работает — пробуем второй IPA (`unsigned`).
  Если и так нет — запасные установщики из плана: AltServer + AltStore Classic или Impactor.
  Важно: **один установщик на один Apple ID** — программы отзывают сертификаты друг друга.
- **Ошибка про лимит App ID** («You may only register 10 App IDs every 7 days») — бесплатный аккаунт даёт 10 App ID за 7 дней, а «Городки» занимают 2
  (приложение и расширение). Не меняй bundle ID и не ставь много разных приложений с этого аккаунта.
- **Приложение перестало открываться через неделю** — истекла подпись. Переустанови той же кнопкой Start,
  данные сохранятся. Можно включить в Sideloadly автообновление (компьютер должен быть включён,
  iPhone — в той же Wi-Fi-сети с включённой синхронизацией по Wi-Fi в iTunes или подключён кабелем).

## После установки

- Следующий шаг — [пробная прогулка](probe-walk.md): две прогулки (способы A и B) проверяют фоновый трекинг
  и Live Activity, а «Лаборатория → Карта» — карту и туман.

- **Не обновляй iOS на демо-телефоне**, пока не проверим, что установщики поддерживают новую версию.
- За 1–2 дня до показа переустанови приложение, чтобы подпись точно не истекла на защите.
