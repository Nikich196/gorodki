## 1. Контекст и цель

**Задача.**
- Семестровый проект по мобильной разработке (БрГТУ).
- Приложение для iPhone, показ преподавателю в **конце декабря 2026** на живом телефоне.
- Нужно минимум 3 пункта из 14 (больше — лучше). За сильный продукт возможен автомат.
- Команда: Никита (дизайн, iOS, продукт) и одногруппник (бэкенд на C#).
- Основной код пишет Claude. Команда должна понимать код и уметь его защитить.

**Листик (14 пунктов):**
1. OAuth.
2. Облачное восстановление.
3. Медиатека.
4. Push.
5. Кэш во внутренней FS.
6. Внешняя FS.
7. Календарь и контакты.
8. Фоновый сервис (Android).
9. PiP-видео.
10. Фоновая геолокация.
11. Дизайн-язык ОС.
12. Сложный интерфейс.
13. NFC и камера.
14. Сложный сервер.

**Концепция (эскиз + пожелания Никиты):** спортивная игра «как Paper.io, но по-настоящему», для бегунов и велосипедистов.
- Ты обегаешь участок, и твоя территория — **ровно по контуру следа**: «сколько пробежал — столько получил».
- Чужую землю можно отбить.
- Есть кланы.
- **Второй режим — «Исследование»:** город под туманом (очертания видны), от дома карта открывается по радиусу вокруг пути, у каждого своя карта «где был / где не был», как в Zenly, и рейтинг «кто открыл больше».
- **Фишки** в случайных местах и **тайники** со спрятанными значками разной редкости.
- **Дуэли** на значки и награды, **«Короли участков»**, **карточка недели** для сторис.
- **Никаких машин.**

## 2. Ключевые решения (подробные ADR — в `docs/adr/`)

**D1. Натив (Swift 6 + SwiftUI) + веб-компаньон.**
- PWA в Safari не получает геопозицию при заблокированном экране (спецификация W3C: обновления позиции идут только видимому документу). У неё нет CoreMotion и шагомера, значит, невозможен античит против машин. Нет NFC, контактов, календаря, Live Activity.
- **Идея Никиты используется как «Городки Web»** (устанавливаемое веб-приложение на GitHub Pages):
  - карта, кланы, рейтинги, инвентарь, приглашения, `/live`;
  - **Web Push бесплатно**;
  - захвата и подбора фишек нет.
- **Покрытие листика:**
  - натив с платным аккаунтом — 13 из 14;
  - без платного — ~10–11 полностью, п.4 и п.13 частично, п.8 как iOS-аналог;
  - PWA — 6–7 из 14.

**D2. Бэкенд: ASP.NET Core 10 LTS.**
- Модульный монолит, вертикальные срезы, Minimal APIs.
- Стек: EF Core 10, Npgsql, NetTopologySuite, PostgreSQL + PostGIS, SignalR, Hangfire.
- Фоновые задачи — гибрид ([ADR 0005](adr/0005-background-jobs.md)): очередь захватов — свой обработчик, Hangfire — только задачи по расписанию (§7.3).
- Без «магии». `global.json` закреплён: .NET 11 не берём.

**D3. Территория: точные векторные «участки» (parcels) за интерфейсом `ITerritoryEngine`.**
- Участок — многоугольник: владелец, лига, уровень и таймеры.
- Захват = «всё, что обведено следом»: объединение граней `Polygonize(Node(кольцо))`, без «дыр» от направления обхода.
- Точность ограничена GPS (±5–10 м). Отрезки «туда-обратно» площади не дают.
- **Самая рискованная подсистема.** Проверка «годится / не годится» — спайк **S13 до 14.10**. Если не проходит, в запасе растровая сетка 1–2 м или уже спроектированные клетки H3 res 12. Контракты API от этого не меняются.

**D4. Карта — MapKit через `MKMapView`.**
- Настройка: `MKStandardMapConfiguration(.flat, .muted)`, `pointOfInterestFilter = .excludingAll`.
- Заливки по тайлам без обводки: один `MKMultiPolygon` на пару (владелец, уровень). Границы — отдельным слоем линий.
- Туман — свой `MKOverlayRenderer`.
- Запасной путь — MapLibre + OSM за протоколом `TerritoryMapRenderer`. Качество карты Бреста проверяем спайком S4.

**D5. Локальное хранилище — GRDB 7 (SQLite, WAL)** в Application Support.

**D6. Реальное время — SignalR** (официальный Swift-клиент 1.0).
- Группа — лига (`Subscribe(league)`), а не тайлы: окно карты — почти местоположение зрителя, серверу его знать не нужно.
- Рассылается только подсказка `TilesChanged` (лига и список тайлов, без версий); версии клиент берёт из `GET /territory` и сам перезапрашивает данные.
- Переподключение бесконечное, после него — досинхронизация через REST.

**D7. Хостинг за $0.**
- **Render Free:** 1 веб-сервис; 750 ч/мес на всё рабочее пространство, поэтому второй сервис заводить нельзя.
- **Supabase Free:** PostgreSQL 17 + **PostGIS 3.3.7 / GEOS ~3.14**. Функций `ST_Coverage*` нет, поэтому покрытие проверяется в NTS.
- **GitHub Pages:** сайт, `config.json`, веб-компаньон, `/live`.
- Пингер cron-job.org с реальным запросом к БД.
- Не используем: Fly.io, Cloudflare Pages/tunnels, Backblaze (заблокированы в РБ); Koyeb, Neon, Oracle, AWS, MinIO.

**D8. Сборка.**
- Xcode 27, Swift 6.4, минимальная iOS 26.0.
- API iOS 27 — только за `#if compiler(>=…)` + `#available`.
- Проект описан в `project.yml` (XcodeGen).
- До MacBook — GitHub Actions: раннер `xcode-27` (preview), резерв — `macos-26`.

**D9. Распространение.** Конфигурации **Free** и **Paid** (xcconfig): свои bundle ID, entitlements, App Group, Google Client ID.
- **До Mac:** CI → IPA (подпись ad-hoc с entitlements) → Sideloadly (отдельный бесплатный Apple ID, 7 дней).
- **После Mac:** Xcode.
- **С платным аккаунтом:** подпись на год; TestFlight (внешние тестеры, ~1 день на проверку), выгрузка **только вручную с Mac**.
- «200+ игроков» реально только через TestFlight. Без него — 5–15 игроков, остальным веб-компаньон.

**D10. Вход.**
- Google Sign-In; Sign in with Apple — в Paid.
- Свой JWT на 15 мин + вращаемый refresh-токен: «льготное окно» 60 с, обновление single-flight.
- **Закрытая регистрация по инвайт-кодам** на Сезоны 0–2. Порог **«16+»**.

**D11. Уведомления.** Каналы:
- APNs (Paid);
- Web Push в компаньон ($0);
- живые события SignalR + локальные уведомления + дневная сводка.

Что из этого засчитывается — спросить у преподавателя.

**D12. NFC и камера.**
- Core NFC — только в Paid («Форпосты», метки NTAG213).
- Без платного аккаунта пункт 13 закрыт камерой — честно «частично».
- Камера — свой экран на AVCaptureSession + QR (VisionKit).

**D13. Позиционирование.** Аналоги: INTVL (по данным компании — 2,5 млн+ загрузок, июль 2026; с июля 2026 — вело-режим на отдельной карте), KYRO, RUNHUNTER, Running Empire, RunRaid и ещё не меньше 16 приложений 2026 года — всего не меньше 21 ([глава «Аналоги»](report/01-analogs.md), источники на 23.09.2026). Русский язык отличием не является. Наши отличия:
- укрепления и осады, угасание земли;
- **режим «Исследование»** (туман Бреста, % открытого);
- **тайники со значками** и «Коллекция»;

Проверка по источникам (23.09): контур по петле, отдельная вело-карта, кланы, обрезка 200 м (у Strava — по умолчанию) и «% открытого города» у конкурентов **уже есть**. Подтверждённые отличия — осады и лимиты снятия, дуэли, тайники как постоянный слой, публичная карта с задержкой, открытые правила античита и их сочетание в одном приложении.

На защите честно называем аналоги.

**D14. Понятность важнее модности.**
- Не берём TCA, SwiftData, MediatR, AutoMapper.
- HybridCache, OpenTelemetry/Seq, ArchUnitNET, Verify — в Could.
- **Для записи геометрии — один движок** (NTS или PostGIS, выбор по спайку S13).

**D15. Секреты других проектов в «Городки» не попадают.**
- Отдельный APNs-ключ «Gorodki» лежит только в Render.
- TestFlight выгружается вручную.

**D16. Две лиги: «Бег» (ходьба + бег) и «Вело».**
- `league_id` есть в схеме с первого дня.
- Режим выбирается при «Старте». Смена режима начинает новый отрезок и сбрасывает след. Петля не может охватывать два отрезка.
- **Сезон 0:** территория — только «Бег»; «Исследование» — «Пешком».
- **С Сезона 1:** вело-слой «Исследования» и вело-карта территории. Включаются флагом конфига после красной команды (записи поездок на машине, автобусе, велосипеде) и при ≥5 активных велосипедистах (порог настраивается).
- **Общей карты с коэффициентами нет:** площадь растёт как квадрат периметра, а «машина под видом велосипеда» портила бы землю бегунам.

## 3. Правила игры

Все числа хранятся в **версионированном** `game_config`. Телефон берёт конфиг при каждом «Старте». Забег проверяется той версией, с которой начат.

### 3.1 Цикл («Захват»)
Старт (лига) → след → петля → церемония → участок твой ровно по контуру → чужое внутри ослабевает или переходит к тебе → укрепляешь визитами → клан держит кварталы Арены → очки сезона → Зал славы.

### 3.2 Захват — точный контур
- **Триггер на телефоне.**
  - Отрезок пересёк свой след **или** подошёл к прежней точке ближе R. R = `clamp(1.62·√(acc_i²+acc_n²), 20, 50)` м, по умолчанию 40.
  - Путь между этими местами ≥150 м.
  - Телефон шлёт **заявку петли** `(start_seq, end_seq)` и сразу отправляет незаконченный чанк.
- **Сервер проверяет заявку** той же версией алгоритма:
  - кольцо из проверенных точек (упрощение 2 м);
  - замыкающая хорда ≤ R;
  - `P = union(Polygonize(Node(кольцо)))` — всё, что обведено;
  - снап к сетке 0,1 м в UTM 34N;
  - минус маски (§3.3).
  - `capture_id = UUIDv5(run_id, end_seq)`.
- **Фильтры:**
  - площадь ≥ `A_min` (старт 2 500 м², калибровка на полевом тесте №1);
  - «не узкая»: `NOT IsEmpty(Buffer(P, −R_min, mitre))`, `R_min` = 9 м.
  - Морфологического «открытия» нет: оно скругляет углы и ломает точный контур.
- **Кольцо >3,5 км²:** не засчитывается, игроку объясняется причина. Ручной очереди нет.
- **Лимиты:** ≤30 захватов в день, суточная площадь (конфиг), забег ≤4 ч, один активный забег.
- **v2:** Paper.io «вышел со своей земли и вернулся» (онлайн): `Polygonize(Node(свой контур ∪ след ∪ окно))`, берутся грани, смежные со следом и не касающиеся окна.

### 3.3 Участки: уровни, осада, угасание, щиты
**Порядок применения правил:** маски → щиты → клан → лимиты снятия уровней → множители.

- **Маски** (не захватываются):
  - вода, ж/д, магистрали, военные объекты, кладбища, погранполоса;
  - **мемориалы** (Брестская крепость и др.) — только значок «Посетил», тексты уважительные;
  - маски готовятся офлайн из OSM (§7.3);
  - состав и ширина (решено 25.09, [вопросы OSM](decisions/osm-questions.md)): ж/д — пути ±10 м и площади станций; «магистрали» — `motorway` и `trunk` без пешеходного доступа, ±12 м; мемориал — по контуру, точечный памятник — круг 50 м; военные объекты — из OSM и ручные добавления; погранполоса — ширина из официальных правил, пока её нет — слоя нет;
  - новая маска действует только на новые захваты (перед Сезоном 0 карта очищается, §3.4).
- **Уровень 1…3.**
  - +1 за визит не чаще раза в 20 ч.
  - Визит — ≥50 м следа внутри участка или повторный захват.
  - Не считаются первые и последние 200 м забега и приватные зоны.
- **Вражеский участок внутри нового контура:**
  - L1 — часть внутри переходит к тебе на L1;
  - L2/L3 — часть внутри остаётся у владельца с уровнем −1 («трещина»).
  - **Осада:** треснувший кусок нельзя укреплять 24 ч.
  - **Лимиты снятия:** ≤2 уровней за 20 ч от всех нападающих (3 в рейде); ≤1 уровня от одного нападающего.
  - Состояние куска (уровень, осада, счётчики) наследуется при разрезании.
- **Большая петля ослаблена:** если P >0,5 км² (в вело-лиге порог в 4 раза больше — 2 км²; P — площадь самой петли после масок), вражеская земля внутри только помечается как «спорная» и не переходит. Берутся нейтральная земля и «Ничейные земли».
  - Вражеские L2/L3 внутри тоже не трогаются: без трещины, осады и счётчиков снятия — только пометка «спорная».
  - «Спорная» — пометка на карте на 24 ч, без игровой силы: владелец видит, что на его землю покушались, и может её освежить.
- **Клан.**
  - Земля соклановцев не отбирается; обводя её, ты освежаешь им угасание.
  - Принадлежность считается по текущему составу клана.
  - После выхода или исключения из клана — 72 ч до вступления в другой; земля остаётся у игрока (она личная).
  - Нельзя вступить в клан, на чей квартал идёт рейд.
- **Угасание — ленивое:** уровень вычисляется при чтении. На семестр −1 уровень за 6 дней без визита. L1 без визита уходит в нейтральную и 3 дня видна «призраком».
- **Щиты.**
  - 12 ч при смене владельца (в квартале рейда — 3 ч).
  - Щит новичка 24 ч: выключен в Сезоне 0; снимается, если новичок сам напал.
- **Анти-мультиаккаунт.**
  - Захват засчитывается одному аккаунту на устройство в сутки.
  - Аккаунт моложе 48 ч или с пробегом меньше 3 км уровни не снимает.
  - Бонус за инвайт — после первого валидного километра приглашённого с другого устройства, ≤3 бонусов за сезон.

### 3.4 Сезоны — по 2 недели на семестр
- **С0:** 16–29.11 (бета). **С1:** 30.11–13.12. **С2:** 14.12 → показ.
- **Мягкий сброс:**
  - уровни → 1; «последний визит» сдвигается так, чтобы участку осталось меньшее из двух: срок угасания одного уровня (6 дней) или сколько оставалось до исчезновения. Живая земля в момент сброса не исчезает, давно брошенная уходит раньше;
  - очки → 0;
  - щиты снимаются, а с ними осада и окно снятия уровней;
  - за удержание дают очки только участки, которых касались в этом сезоне: владелец взял участок или освежил его **своим** забегом (освежение соклановцем не считается). Петля относится к сезону по времени замыкания, а не обработки.
- **Старт Сезона 0 (16.11) — с чистой карты:** земля полевых тестов стирается, тесты преимущества не дают.
- **Зал славы:** снимок карты, топ-3, топ-клан. При удалении аккаунта игрок обезличивается.
- Смена сезона и ежедневный срез готовы **до 16.11**.

### 3.5 Очки (SP) — баланс «пешеход против бегуна ≤3×»
- **Единица площади — «сотка»** (100 м²), понятно в Беларуси.
- **Захват:**
  - ступени по площади (на захват и на сутки, с убывающей отдачей);
  - × ценность земли: город 1,0; поле, лес, промзона 0,5; **Арена ×2** — всё с Сезона 0, слой землепользования — в `osm-pipeline` v1;
  - вражеская земля и снятый уровень дают бонус.
- **Удержание:** ежедневный срез в 00:00 по Минску, ступени, потолок в зачёт.
- **Дистанция:** +10 за км, ≤20 км в день. В вело-лиге ×0,33.
- **Прочее:** квесты (50 / 200), серия (+10), контроль квартала (+50).
- **Множители:** «Гроза гигантов» ×1,5; штраф за травлю слабого ×0,5.
- Точные числа — в конфиге. Цель подтверждается симуляцией 20 ботов на 30 дней (материал для записки).
- Рейтинги — по ежедневному снимку, только локальные, **раздельно по лигам**.

### 3.6 Кланы, «Арена БрГТУ», рейды
- **Кланы:** 3–12 человек, лидер и до 2 офицеров. Оттенок цвета уникален в Арене. Отношения на карте передаются узором.
  - Вступление — по коду-приглашению от лидера или офицера: без заявок и модерации.
  - Название — 3–24 символа (буквы, цифры, пробел, дефис), уникально без учёта регистра, простой фильтр мата. Меняет лидер, раз в сезон; спорное название по жалобе переименовывает админ.
  - Цвет — свободный оттенок из палитры кланов (12 оттенков); на карте — цвет владельца + узор отношения (§6.3). Кланов больше 12 — оттенок повторяется, различает узор. Строгая уникальность «в Арене» — после границ Арены (конвейер OSM).
  - Лидер ушёл — лидерство переходит офицеру, иначе самому давнему участнику. Клан меньше 3 человек остаётся, но «неполный»: не участвует в рейдах и контроле кварталов, пока снова не наберёт 3.
- **Арена БрГТУ:** радиус ~1,5 км вокруг корпусов и общежитий.
  - Корпуса и общежития — кандидаты из OSM, список утверждает Никита. Граница Арены — по улицам, ~1,5 км — ориентир.
  - Ценность ×2, 6–8 «кварталов» по крупным улицам: разрез предлагает Claude, Никита правит.
  - Контроль квартала — относительное большинство при доле ≥15% и ≥2 вложившихся участниках.
- **«Ничейные земли»** (Must) — честно подписанная нейтральная фракция: засевает Арену уровнем L1 как цели. Фейковых игроков нет.
  - Цели — городские блоки, окружённые улицами: площадь ≥ `A_min`, нигде не уже 2·`R_min`, не больше `NeutralBlockMaxArea` (стартовый ориентир ~1 га — квартал с обходом ~400 м, §3.18; калибруется).
  - Засев — раз в начале сезона: все блоки-кандидаты Арены, отдельной доли нет. Если после подсчёта по OSM целей на сезон окажется мало — досев.
  - Земля фракции не угасает; для захвата она ничья (берёт любой, в том числе новичок). Щитов, рейтингов, контроля кварталов и клана у фракции нет.
- **Рейд** (Should):
  - объявление за ≥48 ч, раз в неделю;
  - победитель — клан с наибольшим приростом площади в квартале за выходные;
  - событие добавляется в календарь.
- **Чата нет** — ссылка на Telegram-группу.

### 3.7 Прогресс и награды
- XP, уровни, титулы, серия с «заморозкой», квесты: без ночных требований и без >10 км.
- **Значки трёх видов:**
  - за достижения;
  - **тайники** (§3.12);
  - **дуэльные** (§3.14).
- **Редкость:** обычный / редкий / эпический / легендарный.
- Покупок нет; награды — косметика и игровые предметы (§3.11).
- **«Ночь» = 23:00–06:00:** в это время нет фишек и нет квестов. Вечерние забеги засчитываются полностью, с напоминанием о светоотражателях.

### 3.8 Социальное
- Друзья — только взаимные (QR или ссылка).
- Лента (по умолчанию «друзья и клан»): респекты, комментарии, жалобы, блокировки, фильтр мата.
- **Живых позиций друзей нет** (решение Никиты).
- Приглашение из контактов — без серверной сверки хэшей: хэш белорусского номера перебирается за секунды.

### 3.9 Античит (слоями; честно — это вероятностная защита)
**Слой 1 — телефон:**
- точность ≤25 м для захвата (≤35 м для первой петли новичка);
- возраст точки ≤10 с, монотонное время, телепорт = разрыв;
- флаги симуляции геопозиции — подсказка для оценки доверия, не приговор.

**Слой 2 — правила отрезков (нарушение рвёт след, причина видна):**
- **Лига «Бег»:**
  - скорость >25 км/ч за 30 с; >19 км/ч за 5 мин;
  - CoreMotion «транспорт» ≥20 с или «велосипед» ≥30 с → предложение «Переключиться на Вело?»;
  - шагомер: 0 шагов при ≥1 м/с за 20 с или длина шага вне 0,3–2,2 м;
  - `nil` у шагомера — «неизвестно», не ноль.
- **Лига «Вело»:**
  - скорость за 5 с >60 км/ч, за 30 с >48, за 60 с >42, за 5 мин >36;
  - «разгон машины»: +25 км/ч за ≤6 с с выходом на ≥35 км/ч;
  - «транспорт» ≥60% из 120 с **и** скорость за 60 с >25 км/ч;
  - маски магистралей и `bicycle=no`;
  - «плато» 22–27 км/ч с малым разбросом (электровелосипед или самокат) — только флаг доверия.

**Слой 3 — сервер:** повторная проверка и оценка доверия. Признаки: одинаковая точность у всех точек, идеальные интервалы, нет шагов, повтор чужой формы маршрута, >60 км в день пешком.

**Слой 4 — игровые лимиты**, щиты, инвайты.

**Слой 5 — наказания:** теневой бан → заморозка 7 дней → бан. Откатываются только куски, которых после этого никто не трогал. Угасание за время, пока земля была отнята, жертве не засчитывается: её «последний визит» сдвигается на это время.

**Разрешение «Движение» обязательно для захвата.**

**Известные дыры (говорим открыто):**
- медленная машина <30 км/ч, автобус, электровелосипед или самокат в вело-лиге — отсюда отдельная карта;
- чужой телефон;
- изменённый клиент или скрипт к API (без App Attest).

### 3.10 Режим «Исследование» (туман)
- **Суть:**
  - весь город под полупрозрачным туманом, улицы под ним видны («слегка затемнено»);
  - валидное движение открывает карту в радиусе **25 м** вокруг пути (с «Радаром» — ×2);
  - у каждого своя карта «где был / где не был».
  - Карта открывается **только во время забега или поездки** (разрешение «Всегда» не нужно). Во время открытия действуют правила лиги: из машины туман не открывается.
- **Старт «от дома»:**
  - при онбординге игрок ставит точку «Дом», вокруг открывается круг ~500 м;
  - **точка «Дом» и этот круг хранятся только на телефоне**: сервер их не знает, в статистику они не идут. Альтернатива — старт от Арены.
- **Слои:**
  - «Пешком» и «Вело» (вело — с Сезона 1), «Всего» — сумма;
  - **пожизненная карта** (не сбрасывается);
  - **сезонная** — сбрасывается каждый сезон, чтобы соревноваться активностью, а не одним стажем.
- **Статистика:**
  - открытые гектары;
  - **% Бреста** от «достижимой» площади: пешеходные пути OSM с буфером 25 м в границах города минус маски, иначе 100% недостижимы. Пешеходные пути — дорожки и улицы, по которым ходят пешком (кроме `motorway` и `trunk` без пешеходного доступа); мемориалы не вычитаются — обход крепости прибавляет процент;
  - % по районам (Ленинский и Московский, по границам OSM) и кварталам Арены;
  - «+N га сегодня».
  - Достижения: «Квадрат» (полностью открытый квадрат), «Открыл все парки», «100% Арены» и т. п. Порог «100% Арены» — ниже 100 % (край полосы GPS не открывает), число — после полевого теста №1.
- **Рейтинги «Кто открыл больше»:**
  - сезон и всё время, раздельно «Пешком / Вело / Всего»;
  - **только числа**: чужие карты исследования не показываются никогда.
- **Приватность.** Карта исследования — персональные данные:
  - по умолчанию видна только тебе;
  - в карточке недели — только числа и закраска районов;
  - «Очистить историю исследований»;
  - карта входит в «мои данные» и стирается при удалении аккаунта.
- **Связь с другими режимами:**
  - «сундуки в тумане» появляются у края твоей открытой области;
  - подсказки тайников открываются исследованием (§3.12).

### 3.11 Фишки («Рюкзак»)
**Смешанная модель:**
- обычные и необычные — **личные** (у каждого свой набор, толкаться не нужно);
- редкие — **общие, «первым трём»** (не одному: меньше гонки и утечки местоположения).

**Сезон 0 — полезные и косметические** (баланс не ломают):

| Фишка | Эффект |
|---|---|
| «Магнит» | R замыкания +20 м на 2 км |
| «Радар» | Радиус открытия тумана ×2 на 3 км |
| «Компас» | Направление к ближайшему тайнику или сундуку |
| «Заморозка серии» | Серия не сгорает за пропущенный день |
| «Сундук» | Стиль следа, рамка аватара, эмблема, XP |

**С Сезона 1, на пробу, после симуляции ботов, флагом:**

| Фишка | Эффект |
|---|---|
| «Щит» | Участок под защитой 12 ч |
| «Таран» | Снимает 2 уровня (в пределах общего лимита) |
| «×2» | Двойные очки захвата на 3 км |

Цель — предметы дают не больше 15% SP.

**Откуда берутся:**
1. **«Припасы»** — за каждые 2 км валидного движения, до 4 в день. Геоданные не нужны. MVP, этап 3b.
2. **Фишки на карте** в пределах Арены. Места — точки-кандидаты каждые 25 м на пешеходных путях OSM. Этап 4.
3. **«Сундуки в тумане»** — личные, у края открытой области.

**Подбор:**
- автоматически на сервере, по проверенным чанкам;
- радиус `clamp(15+acc, 25, 40)` м;
- между подборами ≥250 м и ≥60 с;
- подбор предварительный, пока забег не наберёт 1 км;
- при скорости выше порога лиги фишки скрыты;
- голос «подобрано», строка в Live Activity.

**Рюкзак:** 12 ячеек, срок 7 дней. Активация — только стоя или перед «Стартом». Эффекты меряются **дистанцией**, а не временем.

**Безопасность размещения (маски):**
- переходы, лестницы, тоннели, частная территория;
- ≤12 м от оси автодороги;
- ж/д, вода, военные объекты, кладбища;
- мемориалы +50 м;
- школы, детсады, площадки +20 м;
- больницы, госучреждения;
- погранзона;
- обрезка по границе Бреста (bbox захватывает Тересполь).

**Время:** ночью фишек нет; после заката — только на освещённых путях.

**Приватные зоны из размещения не вырезаются** (иначе вырез выдаёт дом). Подборы публикуются без координат.

**Защита:**
- позиции фишек отдаются точно только в радиусе 1 км от серверного «якоря» активного забега, иначе — счётчики по тайлам;
- лимит частоты запросов;
- детерминированное размещение: `HMAC(ключ сезона, день, тайл)`;
- ключ хранится только в Render и меняется каждый сезон;
- набор точек-кандидатов замораживается на сезон (`candidate_set_version`).

**Лицензия:** атрибуция OSM (ODbL) — «© участники OpenStreetMap» со ссылкой на `openstreetmap.org/copyright`, в том числе на карте, пока на ней видны наши слои из OSM; на карточке недели — короткая подпись. Набор `osm-set-N` — под ODbL, выкладывается отдельно от кода (релиз GitHub, вне git); код — «все права защищены».

### 3.12 Тайники и «Коллекция» (идея Никиты)
- **~40 спрятанных тайников** в безопасных общественных местах Арены и Бреста: парки, набережная, арт-объекты, виды. Распределение: обычные 20, редкие 12, эпические 6, легендарные 2.
- **На карте тайников нет.** В «Коллекции» — силуэты ненайденных значков, редкость и **подсказка-загадка** о месте. Подсказка проясняется, когда открываешь туман рядом.
- **Во время забега** в радиусе ~150 м — «горячо/холодно»: голос и вибрация в кармане. «Компас» указывает направление.
- **Найти** — пройти в 30 м в валидном забеге. Подбор автоматический: «Ты нашёл значок „…“ — ЭПИЧЕСКИЙ!», церемония.
  - Первый нашедший получает золотую рамку.
  - Значок показывает «№ N нашедших».
- **Каждый сезон часть тайников перемещается.** Мемориалы — только уважительные значки «Посетил», вне тайников.
- **Отбор мест:** Claude предлагает кандидатов из OSM → Никита утверждает список. Координаты не уходят на телефон, пока тайник не найден: клиент получает только подсказки.

### 3.13 «Короли участков» (спринт-отрезки)
- **6–10 отобранных отрезков** по 200–800 м: парки, набережная Мухавца, у БрГТУ. Без пересечения проезжей части, желательно освещённые.
- **Корона** — лучшее время на отрезке, раздельно «Бег» и «Вело», за сезон и за всё время. **«Местная легенда»** — больше всех проходов за 30 дней: даёт шанс пешеходам.
- **Засчитывание на сервере:**
  - ворота старта (25 м), затем ворота финиша, по порядку;
  - коридор 30 м;
  - время интерполируется;
  - все точки прошли правила лиги;
  - «бег» быстрее 30 км/ч на отрезке — не засчитывается.
- Уведомление «Тебя свергли с трона на „…“» — высокий приоритет. Корона видна в профиле и на карте.

### 3.14 Дуэли 1×1
- **Кто:** только взаимные друзья одной лиги.
- **Срок:** 1, 3 или 7 дней.
- **Метрика:** захваченная площадь / открытая площадь / дистанция / лучшее время на выбранном отрезке.
- **Ставка (по желанию):** каждый ставит одну фишку из рюкзака, победитель забирает обе.
- **Всегда:** дуэльный значок, редкость растёт с серией побед (бронза → серебро → золото). **Значки «Коллекции» на кон не ставятся:** они вечные.
- Живой счёт и уведомление о смене лидера (в пределах бюджета уведомлений).
- **Защита от злоупотреблений:**
  - правило «одно устройство — один аккаунт»;
  - аккаунт старше 48 ч;
  - ≤2 активных дуэлей;
  - одна пара — не чаще раза в неделю.

### 3.15 Карточка недели
- Каждый понедельник (и в конце сезона) — красивая карточка:
  - «Неделя: 12,4 км · +2,1 га · открыто +1,3% Бреста · 2 тайника · корона на „…“»;
  - карта твоей земли и закраска исследованных районов;
  - процент — пожизненный; в неделю смены набора OSM прирост процента не показывается, только км и га.
- **Приватность:** центр — Арена или район; нет следов, нет дома, нет точных дат.
- **Рендер:** `MKMapSnapshotter` + отрисовщик тумана (снимок сам туман не рисует) + `ImageRenderer`.
- ShareLink в Instagram и Telegram, сохранение в Фото с доступом «только добавление».

## 6. Дизайн

**6.2 Стекло.**
- Только на слое управления: таб-бар, кнопки карты, HUD, «Старт».
- «Старт» — `.glassProminent` цвета игрока, единственный цветной элемент управления.
- Проверять на обоих краях ползунка прозрачности iOS 27.

**6.3 Территории.**
- **Точный контур:** заливка плюс чёткая граница.
- Отношение передаётся узором и толщиной: моё — сплошная, клан — штриховка, враг — бледнее, спорное или треснувшее — «бегущие муравьи», потерянное — призрак.
- Уровень — насыщенностью. Режимы: Игроки / Кланы / Отношения.
- Маски OSM видны на карте: серая полупрозрачная заливка без обводки (штриховка занята кланом, серого нет в палитре игроков). На устройстве проверить, что её не спутать с туманом и «призраком».

**6.4 Туман («Исследование»).**
- Мягкий полупрозрачный слой (альфа 0,6–0,8, калибруется на устройстве) над дорогами, под подписями — улицы видны сквозь туман.
- Мягкие края (размытие).
- Во время забега туман «тает» вокруг точки раз в секунду.
- Отдельная палитра: тёплая «дымка», а не цвет игрока.

**6.5 Палитра игроков** (12, рассчитана с учётом дальтонизма):
Red `#D30931` · Orange `#E66122` · Sun `#F8DB8F` · Lime `#A8CC06` · Forest `#0F7C5D` · Mint `#7EF6E7` · Teal `#5F99A0` · Sky `#90CBF7` · Blue `#1A5AE1` · Violet `#A38AFC` · Magenta `#B70388` · Coral `#E7A69C`.

## 7. Архитектура

### 7.1 Схема
```
iPhone ─REST/OpenAPI─► ASP.NET Core 10 (Render, 1 сервис) ─► Supabase: Postgres17 + PostGIS 3.3.7 (схемы app/hangfire), Storage
  ▲ └─SignalR (лига: тайлы)────┘   ├─ геодвижок участков (NTS или PostGIS — один для записи), растровый движок тумана
  │                                ├─ свой обработчик очереди, Hangfire (расписание), outbox (push), APNs (Paid) / Web Push
  ├─ GRDB, кэш тайлов, слои тумана (растры), Exports/
  └─ config.json (Pages, вшитый список хостов)
GitHub Pages: сайт, политика, компаньон (PWA + Web Push), /live (MapLibre + SignalR JS)
Офлайн-конвейер OSM (ноутбук/CI): Geofabrik → osmium → C#/NTS (без локальной PostGIS) → маски, «достижимая» площадь, точки-кандидаты фишек → импорт в Supabase
```

### 7.2 iOS-клиент
- **Проект:** `project.yml`.
  - Конфигурации Free/Paid (bundle ID, entitlements, App Group, Client ID — из Info.plist, флаг `PAID_SIGNING`).
  - Цели: приложение, `GorodkiWidgets` (Live Activity + виджеты), тесты.
- **Пакет `GameCore`** — чистый Swift без зависимостей, тесты на Windows/WSL:
  - ENU, приём точек, **правила обеих лиг**;
  - детектор петли и заявки;
  - **растеризатор тумана** (сетка G22 ≈5,87 м, штамп круга r=25 м, лимиты разрывов 100/200 м) — общие с C# эталонные векторы;
  - точка в полигоне, площадь, машина состояний забега и отрезков.
- **Отдельные пакеты без SwiftUI** — их тесты идут в CI (`ios-core`) и в WSL:
  - `GorodkiAPI` — клиент из OpenAPI ([ADR 0004](adr/0004-openapi-swift.md));
  - `GorodkiNetwork` — сеть, вход, реальное время (`Networking` и `Realtime`);
  - `GorodkiPersistence` — GRDB;
  - `GorodkiSync` — забег и очередь.
- **Пакет `GorodkiKit`** (SwiftUI и ActivityKit — собирается только на Mac):
  - Platform: Location, Motion, Pedometer, Keychain, Notifications, Photos, Camera, QR, NFC, Calendar, Contacts, PiP, LiveActivity, Speech, BGTasks;
  - DesignSystem.
- Экраны — в цели приложения (`ios/App`).
- **Паттерны:**
  - `@Observable` модель на экран;
  - `AppDependencies`;
  - акторы `TrackingEngine`, `SyncEngine`, `TokenStore`;
  - Swift 6.
- **Трекинг:**
  - выбор API — ADR по S1: `liveUpdates` + `CLBackgroundActivitySession` или `CLLocationManager`;
  - восстановление синхронно в `didFinishLaunching`;
  - источники за протоколами Location / Motion / Pedometer (Live / Replay / Fake);
  - петля → немедленная отправка чанка и `/loops`.
- **Демо-повтор:**
  - свой формат (точки + движение + шагомер);
  - «виртуальное время»;
  - параллельно настоящая фоновая сессия;
  - `source=replay`, значок «ПОВТОР ×20»;
  - доступ только ролям `demo` и `admin`.
- **Карта:**
  - `MKMapView`;
  - заливки по тайлам + слой границ;
  - касание через `UITapGestureRecognizer` + hit-test в GameCore;
  - анимация — `CAShapeLayer`.
- **Туман:** свой `MKOverlayRenderer` на `.aboveRoads`.
  - Маска из растров с уровнями детализации (mip), размытие `vImageTentConvolve_Planar8` (нечётное ядро, буфер на поток), `clip(to:mask:)`.
  - Рисование идёт из нескольких потоков → неизменяемый снимок данных.
  - Во время забега — `setNeedsDisplay(rect, zoomScale:)` не чаще 1 Гц.
  - Проверить, не переворачивается ли маска по вертикали.
  - Тот же отрисовщик — для снимков карточки и PiP.

### 7.3 Бэкенд
**Структура.**
- `Gorodki.Api`: `Features/*`, `Infrastructure/*`.
- `Gorodki.Domain`:
  - Geo: `ITerritoryEngine`, **фасад `GeoOps`** (NTS OverlayNG, `PrecisionModel(10)`; прямые вызовы в обход фасада запрещены архитектурным тестом);
  - Fog (растры, popcount, маски);
  - AntiCheat (две лиги), Scoring, Seasons, Items (HMAC-размещение, эффекты), Caches (тайники), Segments, Duels;
  - `GameClock` (Минск), `GameRules`.
- `tools/`: `Gorodki.BotSimulator`, **`osm-pipeline`** (Geofabrik → osmium → маски, «достижимая» маска, точки-кандидаты, границы Бреста и кварталов Арены; вся геометрия — на C# тем же NTS, что у участков, без локальной PostGIS).
- `load/k6`, `deploy/`, `Dockerfile`.

**Геометрический контракт.**
- Хранение в **EPSG:32634**, сетка 0,1 м.
- Каждая операция наложения — со снап-раундом (`gridSize` 0,1 / `PrecisionModel(10)`).
- Промежуточные результаты — через `ReducePrecision(0.1)`.
- Проверка валидности на входе.
- **Тайлы — квадраты UTM 1×1 км**, ключ `(⌊x/1000⌋, ⌊y/1000⌋)`. Это единый ключ для хранения, блокировок, кэша и подсказок реального времени (группа SignalR — лига, D6).
- Одна строка = один простой полигон внутри тайла.

**Движок участков (запись — одним движком, выбор по S13).**
- **Шаг A — вне блокировок:** кольцо → `P` (Polygonize и Node) → маски → фильтры.
- **Шаг B — одна транзакция:**
  1. `INSERT captures ON CONFLICT DO NOTHING`.
  2. `pg_advisory_xact_lock` по тайлам в отсортированном порядке.
  3. Для каждого тайла:
     - узлование всех границ (участки тайла + `P∩тайл`) сразу;
     - `Polygonize` — разбиение по построению;
     - атрибуты граням через `PointOnSurface`;
     - правила §3.3 по кускам с наследованием состояния;
     - слияние одинаковых соседей;
     - осколки <25 м² или уже 1,5 м поглощаются соседом с самой длинной общей границей.
  4. Проверка инвариантов:
     - валидность;
     - нет перекрытий между владельцами;
     - площадь сохранена в пределах допуска;
     - вне P ничего не изменилось.
  5. Журнал (TWKB прежних кусков, 7 дней на откат), `tile_versions`++, commit. После commit подсказка кладётся в очередь в памяти (`RealtimeHints`), отправляет её `RealtimePump` — без outbox: потеря подсказки ничего не ломает, приложение досинхронизируется при подключении.
- **Ночная перестройка каждого тайла** тем же алгоритмом. Хранимые контуры **не упрощаются**, упрощение только для показа.
- **Рендер:** `/territory?tiles=` → заливки по тайлам (точные, без обводки) + линии границ по контуру, объединённому поверх тайлов. На масштабе Сезона 0 — вся Арена одним кэшированным GeoJSON, земля вне Арены (если захват открыт на весь Брест, §3.19) — по тайлам. Для веба — MVT.
- **Запасной движок** (если S13 провален): растр 1–2 м или H3 res 12 за тем же интерфейсом.

**Туман (растры).**
- `fog_tiles(user_id, layer foot|bike, scope lifetime|season, tile_z14, bits bytea 256×256 бит — Deflate в .NET)`.
- Обновление — **один раз за забег** на тайл (меньше «мёртвых» строк).
- Прирост площади = `popcount(new & ~old)`.
- % = `popcount(explored & reachable) / popcount(reachable)`; маски районов и кварталов.
- Бюджет: ~50–150 КБ на игрока → ~10–30 МБ на 200.

**Фишки.**
- `spawn_candidates(set_version, id, geom, lit, zone)` — замороженный на сезон набор.
- `item_pickups(user, item_uid = UUIDv5, …)` — в БД пишутся **только подборы**.
- `inventory(user, item_type, qty, expires_at)`.
- Размещение вычисляется в памяти (`HMAC` → индексы кандидатов); набор кандидатов загружается из БД при старте.
- `/items/nearby` — только вокруг серверного якоря забега.

**Тайники:** `caches(id, geom — только на сервере, rarity, hint, season_from/to)`, `cache_finds(user, cache, found_at, order_no)`.

**Отрезки:** `segments(id, league, start_gate, end_gate, corridor)`, `segment_efforts(run, segment, time_ms, valid)`, короны — по снимку.

**Дуэли:** `duels(id, a, b, league, metric, start, end, stake_a, stake_b, status)`; счёт по снимкам; итог — задача Hangfire; ставки — транзакционно.

**Остальные данные** (как в v2):
- пользователи и вход: `users(role, age_confirmed, consent)`, `invites`, `refresh_tokens(replaced_by…)`, `devices(vendor_id)`;
- забеги: `runs(league, source, config_version, processed_seq)`, `run_legs`, `run_chunks(content_hash, points bytea)`;
- `parcels(owner, league, level, flags, timers, hit-счётчики, tile)`, `captures`, `capture_log`, `tile_versions`, `outbox`;
- кланы, `districts`, `raids`, `landmarks`, `masks`;
- соцчасть: `posts`, `kudos`, `comments`, `media`, `reports`, `blocks`, `friendships`;
- сезоны: `seasons`, `daily_scores UNIQUE`, `job_runs UNIQUE`, `leaderboard_snapshots`, `hall_of_fame`;
- `badges`, `quests`, `privacy_zones`, `outposts`, `notifications`, `game_config`, `consents`.

**Бюджет хранения** (500 МБ, при превышении — только чтение):
- сырые точки 14 дней, компактно;
- журнал короткий;
- растры тумана сжатые;
- `/health/ready`: размер БД, число соединений, число участков и вершин;
- оповещение на 350 МБ.

**Конвейер забега.**
- Чанки идемпотентны (хэш содержимого).
- Обработка по непрерывному префиксу под блокировкой забега.
- Для каждого проверенного фрагмента **по одному проходу**:
  1. правила лиги;
  2. заявки петель → движок участков;
  3. штамп тумана;
  4. подбор фишек и тайников;
  5. засчитывание отрезков.
- Тяжёлое — асинхронно: ответ «принято», результат — подсказкой SignalR и через REST. Outbox — для push-уведомлений (§3.17).
- Прочее как в v2:
  - устаревание захватов старше 3 ч после `t_eff`;
  - откат только нетронутых кусков;
  - фоновые задачи — гибрид ([ADR 0005](adr/0005-background-jobs.md)): очередь захватов, визитов, тумана и откатов — свой обработчик (`CaptureWorker`: по сигналу, строго по одному); задачи по расписанию (срез в 00:00, смена сезона, итоги дуэлей, часовые чистки) — Hangfire, подключается с первой из них; дашборд — только чтение, роль `admin`;
  - все фоновые задачи идемпотентны, время Минска;
  - пулы соединений: приложение 8, Hangfire 3;
  - фото обрабатываются в запросе (NetVips), без оригиналов;
  - безопасность: `FallbackPolicy`, роли, лимиты по IP, IDOR-тесты;
  - Supabase: Data API выключен, схемы `app`/`hangfire`, RLS без политик, Storage приватный, PostGIS в `extensions`.
- **Тесты на образе `supabase/postgres:17.6.1.175`** — PostGIS 3.3.7, как в проде. Архитектурный тест запрещает функции PostGIS 3.4+.

**Тесты.**
- Сценарные тесты правил (включая «сценарий показа», «откат X после Y», «потерянный refresh»).
- **Геодвижок:**
  - корпус патологических петель: восьмёрка, самоналожение, спираль, «туда-обратно», почти дубли точек, осколки, обход в разных направлениях;
  - **property-based тесты (CsCheck)**: 10 000 случаев с инвариантами;
  - «растровый оракул» 0,25–0,5 м;
  - эквивалентность параллельных захватов последовательному повтору (Testcontainers).
- **Туман:** эталонные векторы Swift = C#.
- **Отрезки:** синтетические проходы.
- **Фишки:** детерминизм размещения, маски, лимиты.
- **Дуэли:** ставки атомарны.

## 12. Риски

| Риск | Что делаем |
|---|---|
| **Геодвижок точных участков** (надёжность, скорость на 0,1 CPU, дробление) | Спайк S13 до 14.10, фасад `GeoOps`, снап-раунд, property-тесты, запасной растр или H3 за `ITerritoryEngine` |
| PostGIS 3.3.7 на Supabase | Тесты на supabase-образе, запрет функций 3.4+, покрытие проверяем в NTS |
| **Разрастание объёма** (туман, фишки, тайники, отрезки, дуэли, вело) | Жёсткий порядок Should, заморозка Д−14, всё за флагами конфига, туман только «Пешком» в воротах |
| Вело-лига: машины и электровелосипеды под видом велосипеда | Отдельная карта, «красная команда», оценка доверия, честно в записке; включение только флагом |
| Туман в MapKit (скорость, многопоточность, мягкие края) | S4-туман, неизменяемый снимок, mip-уровни, запасной тайловый оверлей или MapLibre |
| Опасные места фишек и тайников | Маски (переходы, дороги, вода, школы и т. п.), ночью ничего, после заката — только освещённые пути, отбор тайников вручную |

| GPS-шум | Адаптивный R, фильтр ширины, калибровка; «точно» — в пределах GPS |
| Не можем объяснить код | Простые паттерны, ADR, CodeTour, «ката», пробная защита |

| 99-З | 16+, согласие, инвайты, удаление, EU |

  - фишки: детерминизм, маски, лимиты;

- [ ] стоянка;
