# Как мы работаем

Короткие правила для всех, кто пишет в репозиторий «Городков»: Никиты, одногруппника и Claude.
Полный план проекта — в [docs/PLAN.md](docs/PLAN.md), ход работ — в [docs/JOURNAL.md](docs/JOURNAL.md).

## Устройство репозитория

```
gorodki/
├─ ios/            приложение для iPhone (Swift, SwiftUI)
│  ├─ project.yml  описание Xcode-проекта (XcodeGen), сам .xcodeproj не хранится
│  ├─ Config/      настройки сборок Free и Paid (.xcconfig)
│  ├─ App/         код приложения
│  ├─ Widgets/     расширение: Live Activity и виджеты
│  └─ Packages/    GameCore — игровая логика (тесты на любой ОС), GorodkiKit — общий код iOS
├─ backend/        сервер на C# (ASP.NET Core 10)
│  ├─ src/         Gorodki.Api — веб-сервер, Gorodki.Domain — правила игры
│  └─ tests/       тесты (xUnit v3)
├─ docs/           план, журнал, архитектура, решения (ADR), инструкции, записка
└─ .github/        CI (GitHub Actions), шаблоны задач и PR
```

## Ветки и Pull Request

- В `main` напрямую не пишем: каждая правка идёт через ветку и Pull Request.
- Ветка называется латиницей: `тип/коротко`, например `feat/health-endpoint`, `fix/loop-detector`, `docs/journal`.
- PR сливается, когда CI зелёный. Одобрение не обязательно, но PR друга сливает Никита после комментариев Claude.
- Один PR — одна задача. Большое лучше разбить.

## Коммиты

Формат [Conventional Commits](https://www.conventionalcommits.org/ru/), описание — по-русски:

```
feat(backend): эндпоинт /health с игровым днём по Минску
fix(ios): Live Activity не завершалась после остановки забега
docs: журнал за 23.09
```

Типы: `feat` (новое), `fix` (исправление), `test`, `refactor`, `docs`, `build`, `ci`, `chore`.
Область в скобках: `ios`, `backend`, `web`, `design`, `docs`, `infra`.

## Код

- Имена в коде — по-английски. Комментарии, документация, ADR и тексты для игрока — по-русски.
- Код должен быть понятен и объясним на защите. Без «магии»: никаких библиотек и паттернов ради моды.
- Всё время — через `TimeProvider` / `GameClock` (сервер) и внедряемые часы (iOS), чтобы тесты могли его подменить.
- Правила игры — в `Gorodki.Domain` и `GameCore`, с тестами. Числа (радиусы, пороги, очки) — в игровом конфиге, не в коде.

### Сервер (C#)

- Версии NuGet-пакетов — только в `backend/Directory.Packages.props`.
- В CI любое предупреждение компилятора — ошибка. Локально — просто предупреждение.
- Запуск: `dotnet run --project backend/src/Gorodki.Api` → http://localhost:5080/scalar.
- Тесты: `dotnet test --solution backend/Gorodki.slnx`.

### iOS (Swift)

- Swift 6, минимальная iOS 26.0. Возможности iOS 27 — только за `if #available(iOS 27, *)`.
- Оформление проверяет `swift format lint` (настройки в `ios/.swift-format`).
- Логика без UIKit и SwiftUI — в пакет `GameCore`: её можно тестировать на Windows через WSL (`swift test`).

## Задачи

Задачи — в [Issues](https://github.com/Nikich196/gorodki/issues), этапы — вехи (Milestones).

| Метка | Значение |
|---|---|
| `area:ios`, `area:backend`, `area:design`, `area:infra`, `area:docs` | Часть проекта |
| `type:feature`, `type:bug`, `type:spike`, `type:chore` | Тип работы |
| `для-друга` | Задача для одногруппника по серверу |
| `нужно-решение-Никиты` | Без решения Никиты дальше не двигаемся |
| `проверка-на-улице` | Проверяется только на живой прогулке с телефоном |
| `платный-аккаунт` | Нужен платный аккаунт разработчика Apple |
| `режим-mac` | Нужен Mac (полировка, Instruments, TestFlight) |

### Задачи для друга

- Никогда не на критическом пути: если задача задержится, никто не ждёт.
- Каждая — до 1,5 часа, не чаще одной в две недели, с крайней датой.
- Падающие тесты заранее лежат в `main` с `[Fact(Skip = "ЗАДАЧА #NN")]`. В PR снимаешь `Skip` и добиваешься зелёного.
- В коде заглушки помечены `// ЗАДАЧА #NN: …`.
- После крайней даты задачу доделывает Claude, а ты разбираешь решение: на защите объяснять нужно всё.
- В описании PR — 5 строк «своими словами»: как это работает.

## Безопасность — репозиторий публичный

- **Секреты никогда не попадают в код**: ключи, пароли, токены, `.p8`/`.p12`, строки подключения.
  Они живут только в GitHub Secrets и в переменных окружения Render.
- **Координаты тайников и ключ размещения фишек** не коммитим: иначе любой найдёт их в репозитории.
- **Треки и данные игроков** не коммитим. GPX — только очищенные, только в `testdata/gpx/`:
  без 300–500 м с концов, со сдвигом времени, без метаданных. Эталонные забеги записываем со старта у корпуса, не от дома.
- Скриншоты для README и записки — только на демо-данных.
- Если секрет всё-таки попал в коммит, сразу скажи Никите: ключ нужно **перевыпустить** — удаления из истории мало.
